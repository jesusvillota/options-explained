## <span class="section-tag">Hook</span>Simulation looks forward; exercise looks back

Monte Carlo (Chapter 33) simulates paths forward in time. Pricing an American option works backwards: at each date,
the holder compares exercising now with the value of continuing, and the value of continuing depends on what will be
optimal later (Chapter 13). On a tree, each node knows its children. On a simulated path, a point at time $t$ has
exactly one future, so it can't tell you the *expected* value of continuing.

The brute-force fix, a fresh simulation from every point of every path, is hopelessly expensive. In 2001 Francis
Longstaff and Eduardo Schwartz found a way to get the continuation values from the same set of paths by
**regression**.

## <span class="section-tag">Intuition</span>Learning the value of waiting

Fix one exercise date. Every in-the-money path has a stock price there and, further along, an actual cash flow it went
on to earn under the exercise rule for later dates. Plot one against the other: a noisy cloud, because each path saw
only one of many possible futures. But a curve fitted through the cloud estimates the *average* future cash flow given
today's stock price. That's the continuation value.

The algorithm works backwards from expiry. At each date it regresses, decides which paths exercise, and updates
their cash flows. At the end, the price is the average discounted cash flow over all paths.

<Callout type="key" title="Two sources of error, opposite signs">
The exercise rule found by regression is never quite optimal, and a suboptimal rule earns less. So Longstaff–Schwartz
is biased <strong>low</strong>. The regression also sees the same noise it's tested on, which biases it slightly
high. Using the realised cash flows (not the fitted values) for the price keeps the net effect a small low bias.
Andersen and Broadie's dual method gives a matching upper bound.
</Callout>

## <span class="section-tag">Formalisation</span>Optimal stopping by regression

The American price is an optimal stopping problem over exercise dates $t_1 < \dots < t_M = \Time{T}$:

$$
V_0 = \sup_{\tau}\;\mathbb{E}^{\mathbb{Q}}\big[e^{-\Rate{r}\tau}g(\Spot{S_\tau})\big],
\qquad g(s) = (\Strike{K} - s)^+ .
$$

Dynamic programming gives the backward recursion

$$
V_{t_m} = \max\Big(g(\Spot{S_{t_m}}),\; C_{t_m}\Big), \qquad C_{t_m} = \mathbb{E}^{\mathbb{Q}}\big[e^{-\Rate{r}\Delta t}V_{t_{m+1}} \,\big|\, \Spot{S_{t_m}}\big] .
$$

The conditional expectation $C$ is a function of the current state. **Longstaff–Schwartz** approximates it by a linear
combination of basis functions, here $1, x, x^2$ with $x = \Spot{S}/\Strike{K}$:

$$
C_{t_m}(s) \approx \beta_0 + \beta_1 x + \beta_2 x^2, \qquad \hat\beta = \arg\min_\beta \sum_{\text{paths in the money}} \Big(Y_j - \sum_k \beta_k\,x_j^k\Big)^2,
$$

where $Y_j$ is the discounted cash flow path $j$ actually earned after $t_m$. Three choices matter:

- **Regress only in-the-money paths.** Out-of-the-money paths never exercise, and including them distorts the fit
  where it matters.
- **Use realised cash flows, not fitted values,** when moving to the previous date. This keeps the estimate from
  compounding regression errors.
- **Exercise where $g(s) > \hat C(s)$**, and record the payoff as the path's new cash flow.

With $N$ paths and $M$ dates, the cost is $O(NM)$, the same as a European Monte Carlo. The method extends to many
underlyings, where trees and grids are impossible, by choosing basis functions of all the state variables.

**Accuracy.** In the paper's test case, $\Spot{S} = 36$, $\Strike{K} = 40$, $\Vol{\sigma} = 20\%$, $\Rate{r} = 6\%$,
$\Time{T} = 1$ with 50 exercise dates, Longstaff–Schwartz gives about $4.47$, against $4.48$ from a fine finite
difference grid. The code in this course reproduces it in its test suite.

## <span class="section-tag">Recap</span>What to remember

- American pricing needs continuation values, which a single simulated path can't provide.
- **Longstaff–Schwartz** estimates them by regressing realised future cash flows of in-the-money paths on basis
  functions of the state, working backwards from expiry.
- The resulting exercise rule is slightly suboptimal, so prices are biased a little low. Dual methods give upper
  bounds.
- Cost is $O(NM)$, and it works in many dimensions.
